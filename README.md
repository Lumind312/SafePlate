Uses `FoodData.csv` from boltcutters's [food-allergens-and-allergies](https://www.kaggle.com/datasets/boltcutters/food-allergens-and-allergies) dataset.

Either enter recipe manually or use OCR to load from a picture. The app will detect certain allergens and flag them, reporting which ingredients could be dangerous.
